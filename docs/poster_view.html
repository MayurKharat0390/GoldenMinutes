GOLDEN MINUTES

A Decentralized Emergency Response System with Advanced Sensory Triggers
Team: Mayur Kharat, Prince Vallecha, Harshad Thok • Dept: Computer Engineering • Guide: Prof. Sonika Gill Mam

01. Abstract

"Golden Minutes" is a solution to the "Golden Hour" problem—where traffic delays prevent ambulances from reaching victims in time. We built a PWA that connects victims to nearby "Happy Samaritan" volunteers using automated accident detection.

02. Problem Statement

The Gap: In 30% of cases, patients die before reaching the hospital.
  • Traffic Blockades: Ambulances cannot assume a clear path in dense cities.
  • Incapacitated Victims: Traditional apps require the user to "Press a Button". This fails if the user is unconscious.

04A. Fall Detection

Core Logic: 60Hz monitoring of DeviceMotion.

1
Impact: Trigger if Vector Sum > 25 m/s².
2
Verification: Wait for 5s stillness.
3
Alert: Start 15s Countdown (User Cancel Safety).

03. System Architecture

Frontend: PWA
Backend: Django
DB: PostgreSQL
API: Web Audio

04B. Audio Trigger

Uses Web Audio API for spectral analysis to detect distress in noisy environments.

1
Scream Detection:
RMS Amplitude > 0.4 (>85dB) for >300ms.
2
Vernacular AI:
Matches keywords: "Help", "Bachao" (Hindi).

05. Performance

  • Alert Speed: < 200ms latency on 4G.
  • Accuracy: 85% success in drop tests.
  • Boot Time: 1.2s via Service Workers.

06. Future Scope

  • Smartwatch: HRV/Pulse monitoring.
  • Pre-Alert: Send blood group to ER.
  • Drone Dispatch: Automated AED delivery.

07. Conclusion & Impact

Golden Minutes proves that complex safety systems don't need expensive hardware. By leveraging the smartphone in every citizen's pocket, we create a decentralized safety net.

Moving from a "Centralized" to a "Community-First" approach reduces response time from 15 minutes to Golden Minutes, effectively saving lives that are lost in transit.
